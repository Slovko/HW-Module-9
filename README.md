# Домашнє завдання — Модуль 9

Навчальний проєкт про CSS, Flexbox, Grid та адаптивність.

## Сторінки

- `profile-card.html` — картка профілю з окремими стилями у `profile-card.css`.
- `funny-store.html` — каталог шести жартівливих IT-товарів зі стилями у `funny-store.css`.
- `images/` — локальні фотографії товарів, потрібні для автономного перегляду каталогу.
- `Screenshots/` — скриншоти сторінок.

Відкрий HTML-файл подвійним клацанням або через локальний сервер у Cursor. Каталог використовує CSS Grid для товарів, Flexbox для вмісту карток та медіазапити для телефонів, планшетів і комп’ютерів.

Проєкт зроблений на HTML і CSS. JavaScript, Tailwind CSS та backend не використовуються.
